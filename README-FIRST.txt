START HERE

1. Upload every file and folder inside this folder to your GitHub repository.
2. The home page lists your publications and links to the included full-text PDFs.
3. Your site address will be https://pssponduru.github.io after GitHub Pages finishes publishing.
4. The included PDFs are all under 5 MB and contain searchable text.

FOR GOOGLE SCHOLAR ARTICLE-HOSTING SUPPORT

For each additional paper you want to host yourself, copy publications/racer.html to a new file.
Then add the legal PDF (or accepted manuscript) to pdfs/ and replace every
REPLACE / YOUR-GITHUB-USERNAME value in the copied HTML file.

You must also paste the complete author-written abstract on that article page.
Do not use a publisher PDF unless that publisher permits sharing it publicly.

The DOI journal page remains the primary version of a published paper.
